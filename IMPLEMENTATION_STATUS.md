## 📱 HOW TO USE THESE SERVICES

### Example: Using Smart Matching Service
```dart
import 'package:blood_bank/services/smart_matching_service.dart';

final matchingService = SmartMatchingService();

// Match donors to a blood request
final matches = await matchingService.matchDonorsToRequest(
  requestId: 'req123',
  bloodType: 'O-',
  latitude: 23.8103,
  longitude: 90.4125,
  urgency: 'critical',
  maxResults: 20,
);

// Send invitations to top matches
await matchingService.sendBulkInvitations(
  requestId: 'req123',
  donorIds: matches.map((m) => m['donorId'] as String).toList(),
  bloodType: 'O-',
  hospitalName: 'PSTU Medical Center',
  urgency: 'critical',
);
```

### Example: Using Health Tracker
```dart
import 'package:blood_bank/services/donor_health_tracker_service.dart';

final healthService = DonorHealthTrackerService();

// Save health record
await healthService.saveHealthRecord(
  userId: currentUserId,
  hemoglobinLevel: 14.5,
  bloodPressure: '120/80',
  weight: 65.0,
  temperature: 36.8,
  pulse: 72,
  sleepHours: 8,
  hydrationLevel: 'good',
  lastMealTime: DateTime.now().subtract(Duration(hours: 3)),
);

// Get recommendations
final latest = await healthService.getLatestHealthRecord(currentUserId);
final recommendations = healthService.getHealthRecommendations(latest!);
```
